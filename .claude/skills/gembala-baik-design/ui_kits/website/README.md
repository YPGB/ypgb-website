# YPGB Public Website UI Kit

Interactive recreation of the Yayasan Pendidikan Gembala Baik public website. Three screens, switched via the NavBar (no page reload): **Home**, **Berita** (news archive with category filter), **Kontak** (contact form → success toast).

Built entirely from this design system's tokens and components (`NavBar`, `SectionHeading`, `Tabs`, `UnitCard`, `NewsCard`, `Card`, `Input`, `Select`, `Checkbox`, `Button`, `Toast`, `Icon`). `Footer.jsx` is page-only scaffolding, not a system primitive.

No source codebase or Figma was provided for this site — see readme.md. All copy and layout are original, built from the brand's visual foundations. Image slots are placeholders (`imageNote` captions state what belongs there); replace with real photography before shipping.

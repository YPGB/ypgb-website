One-line: directory tile for a school unit — dark umber band with the unit code, then name, address, coordinator, accreditation.

```jsx
<UnitCard abbr="SMA GB" level="SMA" name="Sekolah Menengah Atas Gembala Baik"
  address="Jl. A. Yani, Bangka Belitung Darat" coordinator="Koordinator Unit"
  accreditation="Terakreditasi A" website="https://www.smagb.sch.id" />
```

Notes
- Use in a 3-up grid at `--grid-gutter`. Keep the unit code short enough for one line.

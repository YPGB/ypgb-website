One-line: opens every page section — overline + slab title + optional lead; the overline's terracotta rule is the brand's main section marker.

```jsx
<SectionHeading overline="Tentang Kami" title="Berdiri sejak 1973"
  subtitle="Organisasi sosial Katolik yang bergerak di bidang pendidikan."
  action={<Button variant="link" iconRight="arrow-right">Lihat Semua</Button>} />
```

Notes
- One `level="h1"` per page. Centre only for hero and closing sections.

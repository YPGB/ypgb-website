One-line: the container primitive — 10px radius, 1px quiet border, warm-ink shadow.

```jsx
<Card pad="lg">…</Card>
<Card href="#berita" pad="none">…</Card>
<Card tone="warm" rule pad="lg">Doa Gembala Baik…</Card>
```

Notes
- `pad="none"` when the card holds a full-bleed image or coloured band.
- One shadow level per surface; don't nest shadowed cards.
